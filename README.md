GNX Ver.11.7 — SEO基盤

Ver.11.6をベースに、トップページのdescription/canonical/OGP/robots/構造化データを追加。robots.txtとsitemap.xmlを同梱。

公開方法: ZIPを展開し index.html、assets/、robots.txt、sitemap.xml をGitHubリポジトリのルートに上書き・追加しCommit→Push。

重要: 既存の攻略画面はJS内ルートであり、個別のクロール可能なURLはまだ未実装。今回のサイトマップはトップページのみ。次段階で攻略詳細を実際のHTML URLに分割する。
Google Search Consoleへの登録・所有権確認はユーザー操作が必要。アクセス解析タグは測定ID未設定のため追加していない。
画像の権利確認・広告審査も別途必要。
