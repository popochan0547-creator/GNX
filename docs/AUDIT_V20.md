# Ver.20.0監査と統合方針

添付GNX_Ver20_0(1).zipを使用。420記事/484チェック/345単位と旧台帳・NEXT_STEPSを読取。元ZIP SHA256: 2585310081250d6ce22b1a26ad1dd2ceabf30d33494ba1a3df1931ec4bc6a501。tests/legacy420.jsonとbaseline20.jsonを比較基準として固定。

重複IDを作らず、旧シリーズ・黒狼の仮面を親/関連先として利用。通常と軽装、地点単位と種類単位を区別。同じ品の旧別名チェックは従来ORの1単位。シリーズと各部位は別の手動記録で、相互に推定しない。

旧62品の再照合を全件記録し、38品は明示したフィールドだけを資料確認、24品は要再検証。旧64品すべてを解決したとは扱わない。居合・製法書【6】は表現を限定して差を明記。連続突きの方角と屍山血河の旧版条件も要再検証として保護。戦灰の属性/対応装備/例外は個別出典で確認した範囲だけ追加。修正した記事・収集情報は承認差分JSONで列挙し、ID・チェック・保存形式は変更しない。

既存マップや文言の転載なし。旧34候補のうち33品を新規収録、パッチの鈴玉は未確認で追加しない。防具4シリーズ+34部位/形態、地点29箇所、その他装備・術等8品を追加。
