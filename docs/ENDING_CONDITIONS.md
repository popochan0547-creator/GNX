# エンディング条件一覧

最終戦後の選択前に、狂い火の受領・解除状態をゲーム内で確認。自己チェックは選択可能性の保証ではありません。

|結末|条件|最終選択|注意|
|---|---|---|---|
|壊れかけの時代|最終戦を終え、狂い火で他の選択が制限されていない|壊れかけのマリカで通常の修復を選ぶ|修復ルーン取得を必須にしない。|
|昏き者達|フィアの手順で死王子の修復ルーンを入手|死王子の修復ルーンを用いる修復を選ぶ|フィアの英雄・フォルサクスと、死の呪痕の進行を確認。|
|律の時代|金仮面卿の手順で完全律の修復ルーンを入手|完全律の修復ルーンを用いる修復を選ぶ|王都での謎の報告は灰都化前に進める。|
|絶望の祝福|糞喰いに苗床の呪いを計5個使い忌み呪いの修復ルーンを入手|忌み呪いの修復ルーンを用いる修復を選ぶ|殺害・精薬分岐では修復ルーンの取得手順に進めない。|
|星の世紀|ラニに指輪をはめる段階まで進行|最終戦後のラニの青い召喚サインを調べる|通常の修復を選ぶ操作とは別。|
|狂い火の王|三本指から受領し、ミケラの針で解除していない|最終戦後に狂い火の王となる選択を進める|針は所持だけでは解除しない。ミリセント協力後→マレニアの花→竜王の戦場で使用。受領と解除の記録は現在周回のゲーム内状態を保証しない。|
