# Ver.14.0 統合方針

基準：GNX_Ver13_0_2_Sync_Diagnostics.zip。2026-11-16。

1. ホームのHTML、既存スタイル、背景・アニメーション、アカウントボタンを変更しない。indexの差分は追加の純粋同期ロジック読み込みとキャッシュ識別子のみ。Firebase設定、Auth SDK、認証UI、Firestoreパスは維持する。
2. 既存27レコード・33task.idはそのまま保存し、追加をappendする。版・説明はデータセットレベルで更新。保存schema version=2、localStorageキー、elden-db-v2のFirestore文書は継続する。
3. 不明な将来のtask.idを含むboolean記録も保管する。達成率は現データの既知taskだけを集計。ユーザー記録をデータセット追加時に空へ初期化しない。
4. 新DB同期を全体setDocからrunTransactionによる項目差分統合へ変更。受信・送信に世代ガード、ユーザー別の未送信記録、バックアップを設ける。同じメモの衝突は勝手に解決しない。
5. 本編/DLCのフィルターと資料確認状態を表示。NPCは後半を想像で補わず、掲載範囲・条件・分岐の確認範囲を明示する。
6. 既存ハッシュURLは維持。/GNX/elden/<id>/に静的な参照記事を生成し、進捗UIにリンクする。個別のtitle/description/canonical、関連内部リンク、一覧・sitemapを生成する。
7. 構文、旧データ一致、JSON、検索、進捗、バックアップ、同期ロジックをテストする。ログイン・実Firestoreでの端末同期は設定変更や実データ書き込みを行わず未検証とする。

## 限界

旧Ver.13のクライアントは全体上書きを行うため、新クライアント側の改修だけでその書き込みを防止することはできない。実運用ではPC・スマホを両方Ver.14へ更新する必要がある。Firebaseルールの変更は行わない。
