# GNX Ver.19.0 — 本編アイテム収集データ拡充

添付 **GNX_Ver18_0(1).zip** を基に、131攻略記事・131収集単位・131取得チェックを追加。合計 **298攻略記事・362チェック、収集223単位（本編215/DLC8）**です。旧167記事・231チェックと92収集単位/95対応IDは保持しました。

今回の追加：盾16、結晶雫27、製法書39、魔術24、祈祷25。うち130件は掲載した取得情報を資料確認し、輝石職人の製法書【6】の詳細位置は要再検証。継承分を含む検証済み160、要再検証63で、**検証済み300対象・本編全品の網羅には未達**です。未知の母数から網羅率は出しません。

ホームindex.html、認証/アカウント/Firebase関連ファイルは添付版と同一。ホームのデザイン・画像・背景・アニメーションと、元のバージョン表示も変更していません。公開・プッシュ・Firebase設定変更・本番データ操作は行っていません。

## 動かす

展開先で `python3 -m http.server 8000` を実行し `http://localhost:8000/` を開きます。ELDEN RINGカード→「収集チェック →」。直接の操作URLは `#/elden/collections`、静的資料は `elden/collections/`、個別資料は `elden/<記事ID>/`。**/GNX/** 配下のGitHub Pagesを想定した相対URLとsitemapを生成しています。公開は行っていません。更新時はフォルダ構造を保って全ファイルを揃え、強制再読み込みでキャッシュの混在を解消してください。旧18版の起動データが残っていても、新しいローダーは初期化エラーを起こさず旧データを表示します。

検索、カテゴリ、盾の小/中/大、魔術/祈祷の入手経路、地域、取得状態、伝説、取り逃し確認済み、検証状態を組み合わせられます。地域別の未取得一覧へのボタンもあります。カテゴリ進捗と伝説4群は折りたたんで確認でき、詳細・関連NPC・チャートへ移動できます。

既存の167記事はそのまま読み込み、新規の詳細本文は必要時にカテゴリファイルから読み込みます。索引と全チェックIDは先に読み込むため、読込失敗でも分母や保存進捗を変えません。失敗時は再試行または静的資料ページを使えます。ダウンロードしたファイルを直接開くfile://では詳細fetchが制限されるため、HTTPサーバーを使ってください。

## 収集と保存の単位

収集223単位に対応するチェックIDは226種類です。旧3品の名寄せは各2IDでも1対象として数えます。ID数を収集率の分母にはしません。防具は一式、種子・雫・鍛石は掲載地点、結晶雫は種類単位です。複数の入手先がある同名の結晶雫は1種類にまとめ、2個すべて所持したかを推測しません。

localStorageキー `gnx:elden:progress:v2`、JSON schemaVersion 2、Firestore `users/{uid}/progress/elden-db-v2` は無変更。新規チェックも同じboolean構造です。表示/検索/詳細読込で保存データを自動初期化・移行しません。旧JSONの復元では、ファイルにない現在のIDを保持し、同一IDにあるtrue/falseとメモを確認後に反映します。既存の4,096キー・200KBインポート上限は維持しています。

## 検証の意味と資料

「検証済み」は明示した事実を資料で確認したという意味で、実ゲームプレイでの再現確認ではありません。「要再検証」は旧版継承や資料差/追加確認が必要なもの。「未確認」は十分な根拠のない調査候補です。英語名、周回再取得、全取り逃し条件、数量など未確認の属性はnullにしており、安全や再取得不可を意味しません。
