# 残りの攻略範囲

本編完全攻略は未完了です。今回の拡張は20件に限定し、項目数を増やすための未確認データは登録していません。

- ボス：ライカード、プラキドサクス、フォルサクス、祖霊系、全フィールドボス・地下墓ボスなど未収録多数。
- 武器/防具/タリスマン：全装備の母数・派生/部位別の統一定義が未確定。性能数値・全取得経路・取り逃し条件の照合が必要。
- NPC：ラニの代表的な後半ルートを追加したが、例外ルート未網羅。セレンは終盤分岐のみ補足。ネフェリ新王側の全発生条件、ミリセント、フィア、金仮面などを次に資料照合する。
- ダンジョン：独立カテゴリ8件は到達先・要点のみ。全ダンジョン/祝福/仕掛け/収集地点と照合する台帳が必要。
- 収集：死の根、伝説の装備、全種子・雫などの地点別台帳が未完成。
- チャート：本筋の推奨順8章。エンディング全分岐・全NPC時限条件・DLCチャートは未完成。
- 既存105項目の全主張を独立資料で再照合し、現行パッチ実機再現を行う。
- ブラウザ・スマホ表示、タッチ、Google認証、実Firestore同期は今回未検証。公開前にテスト用アカウントで実施する。

次回は母数と対象バージョンを固定したカテゴリ台帳を用意し、確認済み件数/対象母数を出せる分野から網羅率を計算する。母数不明のまま「100%」や推定百分率を表示しない。旧IDの削除・改名はせず、補足や新しい段階を追加する。
