# Ver.17.0以降の優先順位

## P0：全体台帳の全列挙と照合

今回の台帳は全カテゴリを扱える形式と初期203行であり、ゲーム全要素の列挙を終えた台帳ではない。62行は未収録の調査対象・グループ照合で、固有要素の残数ではない。

1. アプリ/レギュレーションの対象版を実機と公式パッチ情報で固定する。
2. 本編とDLCが混在する索引を分離し、ボスの地域別個体、防具の部位、固有戦技と戦灰の区別を定義して全列挙する。
3. 既存125件は元本文を保存したまま、主張ごとの出典照合で再検証する。出典記事の一部の誤記や古い版の条件を無条件に採用しない。
4. 霊クラゲの遺灰など、旧収集カテゴリにある取得物を新分類と名寄せする。既存IDを削除せず台帳側で関連付ける。

## P1：エンディングに関わるNPC・時限条件

- ミリセント：針の入手、義手、各再会、聖樹の協力/敵対、ミケラの針までを検証。現在は針を渡す導入のみ。
- フィア：短剣、死の呪痕、地下の到達条件と会話順。現在は夢からルーンまでの後半のみ。
- コリン/金仮面：王都の謎、回帰性原理、山嶺と灰都の時限条件。現在は合流まで。
- ネフェリ：新王/傀儡の前提、ケネス/ゴストーク、精薬の扱い。今回新王全行程は実装していない。
- 糞喰い：苗床の呪いの全取得地点と分岐。
- 狂い火：地下の道順、受継ぎと解除の全条件、選択の不可逆性を実機確認。

## P2：伝説・主要地下・収集台帳

伝説武器、魔術/祈祷、タリスマン、遺灰の対象を照合し、取得地点・進捗へ接続。深き根、シーフラ、エインセル、腐れ湖、ノクステラと全主要ダンジョンの入口・仕掛け・ボスを追加。死の根、聖杯の雫、黄金の種子を地点ごとの台帳へ分割。

## P3：運用検証

実ブラウザ・スマホの台帳フィルター、詳細表示、戻る操作、JSON入出力を検証。テスト用アカウントでGoogleログイン・実Firestoreの同期を確認する。今回本番データは操作していない。旧クライアントの全体上書き問題に注意し、両端末の版を揃える。網羅率はカテゴリの全列挙と重複排除が終わるまで表示しない。
