# GNX Ver.18.0 — ELDEN RING収集攻略基盤

添付の **GNX_Ver17_0(1).zip** を基に開発。既存147記事・211チェックは全フィールドとIDを保持し、20記事・20チェックを追加しました。合計 **167記事・231チェック**です。ホームのindex.html、認証・アカウント・Firebase同期ファイルは元ZIPとバイト単位で一致します。公開・プッシュ・Firebase設定変更・本番進捗の操作は行っていません。

本編全収集物の完全網羅版ではありません。伝説4群30対象を優先し、掲載済み収集92単位（本編84/DLC8）を共通チェックで管理する土台を実装しました。一般カテゴリの全母数は未確定です。防具は既存の一式単位を維持し、部位別管理や数量・周回別保存は未実装です。

## 開く

展開したフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。ホームのELDEN RINGカード→「収集チェック →」。直接開く操作URLは `#/elden/collections`。資料用URLは `elden/collections/`、各攻略は `elden/<既存または新規ID>/` です。GitHub Pagesの既存 **/GNX/** 配下で使う相対URLとsitemapを用意しました。更新後に古い画面が出る場合はブラウザを再読み込みしてください。

収集画面ではカテゴリ・種類/部位・地域・取得記録・キーワード・伝説・確認済み取り逃し注意で絞り込み、最大40件ずつ表示します。詳細・NPC・チャートへ移動できます。未分類の武器種や部位は推測で埋めていません。0件のカテゴリも未収録として台帳に残しています。

## 保存と互換性

既存のlocalStorageキー `gnx:elden:progress:v2`、JSON schemaVersion 2、Firestoreの `users/{uid}/progress/elden-db-v2` を変更していません。新しい保存領域や本番データの移行はありません。既存のチェックIDを収集台帳から参照します。

霊クラゲの遺灰・指殺しの刃・暗月の指輪は、それぞれNPC記事と収集記事の旧2IDを1つの収集対象に名寄せしました。読み込み時はどちらかのtrueを取得記録として表示し、保存値は勝手に揃えません。利用者が明示的にチェックを変更したときだけ、対応する旧IDを同時に更新します。収集率は1対象で集計し、従来の全チェック率は231個の旧/新IDを単位として維持します。値が競合している品は注意を表示します。

JSON復元は既存の確認操作後に実行。JSON内の同一IDはtrue/falseの両方を反映し、JSONにない現在のIDは保持します。これにより古い版のバックアップで新規チェックが消えません。メモは復元ファイルの内容になります。未知ID・NPC計画メタデータも保持します。既存の4,096キー/200KBインポート上限は維持しているため、際限なく保存できる設計ではありません。
